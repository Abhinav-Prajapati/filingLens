# filingLens web UI

See the "Web UI" section of the main README. `npm run dev` (needs `filinglens serve` on :8765), `npm run build`.

- `src/lib`: API types and client, number formatting (Indian lakh/crore), theme tokens
- `src/charts`: ECharts option builders (`options.ts`) and the view switcher (`ChartPanel.tsx`)
- `src/components`: Ask thread, answer card, table, sources, Explore dashboard
